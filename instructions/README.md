# Instruções das tarefas agendadas

- `prompt_monitoramento.md`: Radar, Rotação e Auditoria. `prompt_descoberta.md`: Discovery.
- Estas cópias são as autorizadas. As tarefas leem a versão da branch `main` pelo URL raw.
- Altere só por pull request; cada arquivo começa com a versão e termina com `FIM DO DOCUMENTO <nome> <versão>`.
- Não ponha aqui segredos, limites de créditos nem plano de ferramentas pagas: isso fica no prompt privado de cada tarefa.
- O Master Prompt é privado e não entra no repositório.
