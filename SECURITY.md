# Segurança / Security

## Como relatar uma falha

Encontrou uma falha de segurança no site (teiadacorrupcao.io) ou neste
repositório? **Não abra uma issue pública.** Relate de forma privada:

- pelo GitHub: aba **Security → Report a vulnerability**
  (<https://github.com/samfisherbr/teia-corrupcao-brasileira/security/advisories/new>);
- ou por e-mail: teiadacorrupcao@gmail.com.

Descreva o problema, como reproduzir e o impacto. Respondemos assim que
possível e avisamos quando a correção estiver no ar.

Erros de **conteúdo** (um fato, status ou fonte errados) não são falhas de
segurança: veja a página [Correções](https://teiadacorrupcao.io/correcoes).

## Reporting a vulnerability

Please report security issues privately through GitHub's **Report a
vulnerability** button (Security tab) or by e-mail to
teiadacorrupcao@gmail.com, not in public issues.
